# 七财互联 微盟公开资料 V3

整理日期为2026年10月19日。本版为当前公开交付版本，供微盟建档、品牌内容编写和资料审阅使用。

## 资料入口

- 01_微盟填写资料：已填写的三张品牌及产品画像表，以及相同内容的可复制文字版。
- 02_公司与产品介绍：公司简介、注册公司与合规账服务、优势、人群和荣誉的Word及Markdown版本。
- 03_品牌宣传图：六张公司原宣传图，按文件名标注用途。
- 04_公开来源资料：微盟原始空白模板及依据公开来源整理的公司资料底稿。
- 文件清单.csv：逐文件来源、大小与SHA256，便于核对完整性。

公司整体定位为工商财税综合服务，合规账是重点深化方向，注册公司及其他工商财税业务持续提供。公司介绍与两张产品画像沿用相同业务范围。
